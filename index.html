B2B 批发专线：真正出大单的渠道

社交平台负责获客，但批发大单往往来自这些地方。你是源头工厂，这一节的价值可能超过前面所有平台加起来。

韩国本土 B2B 平台

需要韩国营业执照，建议找合作方

  • 도매꾹 / 도매매（domeggook.com）— 韩国最大 B2B 批发平台，无数韩国网店主在这里找货源
  • 주얼토킹（jeweltalking.com）— 韩国代表性的珠宝首饰专业批发平台，最垂直，客户质量最高
  • 업스토어（upstore.kr）— 连接约 3,000 家批发商
  • 도매의신（domesin.com）— B2B 代发货平台
  • 进入方式：找韩国代理公司挂靠，或与韩国贸易商合作，由对方开店你供货

官方与国际 B2B 渠道

免费或低成本，能直接拿到询盘

  • buyKOREA（buykorea.org）— KOTRA 韩国贸易投资振兴公社的官方平台，免费注册，能收到韩国买家询盘，最被低估的渠道
  • 阿里巴巴国际站 — 韩国采购商常用，做韩语版页面 + 韩国关键词投放
  • Global Sources — 韩国中大型买手常用
  • 中国驻韩使馆经商处 / 各地商会 — 会发布采购信息，也能对接韩国华商圈

线下：韩国珠宝批发的心脏

如果能去一趟韩国，效率是线上的 10 倍

  • 首尔 종로 3가 / 4가 귀금속 상가 — 韩国珠宝批发的核心区，成百上千家批发商和零售店聚集，价格比韩国其他地方低 20–40%。这里的老板就是你的目标客户
  • 서울국제주얼리페어（首尔国际珠宝展）— 韩国最大的行业展会，一次能见到几百个采购方
  • 동대문 시장 — 饰品批发也很活跃，偏时尚配饰
  • 操作建议：先线上加到几个종로的老板，再约线下见面，成交率极高

拿到询盘后，怎么谈成

韩国买家最在意的几件事

  • 准备韩语版报价单：FOB 价、MOQ（最小起订量）、打样费、交期，一页说清
  • MOQ 放低一点起步：韩国小店主订量不大，先用 50–100 件的低门槛拿下第一单，后面再涨
  • 主动说清关税和通关：韩国进口关税 + 10% 增值税，谁承担要写明。韩国客户对这个特别敏感
  • 提供成分证明：925 银、18K 电镀厚度、镍含量检测。韩国对饰品的镍释放量有要求，能出检测报告是很强的加分项
  • 物流方案：中韩海运 3–5 天、空运 2–3 天，给客户两个选项
05

侵权红线：发大牌首饰会不会出事

你问的是咨询，这里就把事实讲清楚。

直接回答：会侵权。而且风险不只是封号。

只要你的广告里出现了品牌名、品牌 logo、品牌官方图片，或者复制了有设计权的经典款式，无论你标不标「仿」「同款」「代购」，在法律上都构成侵权。写「本店非正品」这类免责声明没有任何法律效力。

三层风险，从轻到重

  • ① 平台层（几乎 100% 会发生）
    TikTok、Meta、Naver 都有品牌方投诉通道。品牌方投诉 → 视频删除 + 账号扣分，累计几次直接封号。你辛苦养的号一夜清零
  • ② 民事层
    韩国《商标法》（상표법）和《不正当竞争防止法》（부정경쟁방지법），品牌方可要求停止侵权 + 损害赔偿
  • ③ 刑事与海关（最狠）
    韩国商标侵权可处 7 年以下惩役或 1 亿韩元以下罚金。韩国海关（관세청）对仿冒品直接扣押销毁，而且收货人也就是你的韩国客户也会被追责——这等于当场毁掉客户关系

红线清单：这些绝对不能碰

✕ 一律不要出现
  • 标题、标签、关键词里出现品牌名（Cartier、티파니、불가리、샤넬 等，中英韩文都算）
  • 品牌 logo、官方产品图、包装盒、证书、丝绒袋
  • 复制有设计专利或著作权的经典款（如某品牌的螺丝纹手镯、字母系列）
  • 「1:1」「동일 퀄리티」「정품급」「레플리카」「原单」「高仿」这类描述
  • 用品牌名做对比（「像 XX 一样的设计」）也算蹭商誉

绿线：这些做法安全且更赚钱

✓ 放心做
  • 自己的原创设计，以及客户来图定制（OEM / ODM）——这是你作为源头工厂的正牌武器
  • 公有领域的通用元素：素圈、单钻、珍珠、四叶草、莫比乌斯环等，但不要蹭任何品牌名
  • 用材质和工艺做卖点：925 纯银、18K 金电镀厚度、莫桑石 + GRA 证书、镍释放量检测报告
  • 定位成「공장 직영 OEM/ODM」（工厂直营代工）。这个定位拿到的批发客户质量，比蹭大牌高一个量级

一句商业判断

  • 蹭大牌的生意，本质是用你最值钱的资产（供应链和工厂）去换一个随时会爆的雷。一次海关扣货，赔的不只是货款，是韩国客户对你的全部信任
  • 做自主品牌 + OEM，前 3 个月起量慢，但客户会复购、会介绍同行、会签长期协议。做仿品的客户只会比价，而且随时消失
  • 韩国买家里，真正有实力的（网店、品牌方、买手店）没有一个敢碰仿品——他们自己也会被追责。你做正品路线，才进得了这个圈子

以上是行业通行认知与公开法规的整理，不构成法律意见。真要打官司或有具体争议，请咨询中韩两地的知识产权律师。

06

服务器、IP 与手机环境

要不要买家庭 IP、手机要不要刷机——这两个问题的准确答案在这里。

准确的判断：住宅 IP 建议买，哪怕只做一个号

VPS 能不能跑？能。全世界几千万人用机房 IP 的 VPN 刷 TikTok，账号不会因为这一条就被封。所以「VPS 完全不能用」是危言耸听。

但机房 IP 会压低你的推荐量。TikTok 对数据中心 IP 段有一个「信任分」，分低不会封号，但会让你的视频少推给一部分真人。做生意号，起量慢一半就等于白干。

成本对比才是关键：一条韩国静态住宅 IP 一个月 $3–8，一顿饭钱。为了省这点钱去赌一个要做半年以上的生意号，不划算。所以：VPS 必买（做节点用），住宅 IP 建议一起买。

什么时候是「必须」而不是「建议」？做 3 个以上账号矩阵、或用电脑批量运营——这时候没有住宅 IP 就是找死，多个号共用一个机房 IP 等于自己举报自己「这是批量号」。

别猜，自己测：怎么知道你的 IP 干不干净

连上节点后，用手机浏览器打开这两个网站，30 秒就能看出来：

  • ipinfo.io — 看 Company Type。显示 hosting / datacenter 就是机房 IP，显示 isp 才是住宅 IP
  • scamalytics.com/ip — 看风险分。0–25 分安全，25–50 中等，50 以上就该换 IP 了
  • 再打开 TikTok 看推荐流：如果刷出来全是韩语内容，说明区域识别成功了；还在推中文内容就是环境没配对

先买 VPS 测一下，风险分高再补住宅 IP，这样最省钱也最有依据。

反直觉的坑：越便宜的大厂机器，IP 越脏

Vultr、AWS Lightsail、甲骨文免费机——这些是全世界做代理的人首选的便宜货，它们的 IP 段早就被 TikTok 重点标记了。省下的两三美元，换来的是号养不起来。甲骨文免费机尤其严重，被薅得最狠。

IP 分三个档，价格和信任度成正比：

  • 机房 IP（IDC） —— 普通 VPS 自带，$5–8/月。信任度最低，但小众商家的干净段仍可用
  • 原生 / ISP IP —— 少数商家标注「原生IP」「ISP VPS」，$10–20/月。信任度中上，性价比最好的中间档
  • 住宅 IP —— 额外买的代理服务，$3–8 / 个 / 月。信任度最高，但要叠在 VPS 之外

结论：别只看价格挑最便宜的，先测风险分再决定。

韩国 VPS：买什么配置

做节点用，别买高配，纯浪费钱

✓ 够用的配置
  • 2 核 2G / 50G SSD / 1TB 流量就足够了。它的作用只是转发流量，不做计算
  • 甚至 1 核 1G 都能跑，但 2G 内存更稳，不容易卡
  • 只有做直播推流转发时才需要 4 核 8G，你现在用不上
推荐服务商（首尔机房）
  • LightNode（lightnode.com）— $7.71/月起，支持按小时计费，适合先买来测两天再决定。中文界面，支付宝可付
  • Vultr 首尔 — $6/月（1核1G）/ $12（2核2G），全球老牌，稳定
  • AWS Lightsail 首尔 — $5/月起，大厂线路，但注册需信用卡
  • Kamatera — $4/月起，配置可自定义
  • 韩国本土（Gabia / Cafe24 / KINX）IP 更「本地」，但要韩语沟通 + 实名，不建议现在碰

住宅 IP（家庭 IP）：怎么买

做矩阵才需要，一号一 IP

静态住宅 IP（推荐，养号用这个）
  • IPRoyal — 静态住宅约 $2.4–5 / 个 / 月
  • Proxy-Cheap / NodeMaven — 韩国住宅 IP，约 $3–8 / 个 / 月
  • 原则：一个账号绑一个固定 IP，永远不换
按流量的动态住宅（不适合养号）
  • DataImpulse 约 $1/GB，Decodo 约 $4/GB，Bright Data $8.4/GB 起
  • 这类 IP 会轮换，TikTok 最讨厌 IP 乱跳，只适合做数据采集，别拿来养号
指纹浏览器（只有用电脑做多账号才需要）
  • AdsPower / BitBrowser / 比特浏览器，约 $10–30/月
  • 纯手机运营的话，这一项可以跳过

手机怎么准备：不用刷机，但要设对

千万别刷机、别 root、别越狱

刷机（刷第三方系统）、root、越狱、解锁 bootloader —— 这几件事一件都不要做。很多人以为这样能「改机防关联」，实际上完全反了：TikTok 会主动检测设备是否被 root / 越狱，一旦检测到，你的设备信任分直接掉到底，比机房 IP 严重得多。

同理，不要装那些「改机软件」「一键新机」工具。它们都要 root 才能用，等于自己给自己贴标签。

该做的：一台干净手机

必做

不用刷机，恢复出厂设置就够了

✓ 该怎么做
  • 最好用一台专门的手机。二手 iPhone 也行，几百块的事，别和你日常用的手机混着用
  • 如果这台手机以前登过 TikTok 或抖音，恢复出厂设置（设置 → 通用 → 传输或还原）。这一步是为了清掉旧的设备标识，跟刷机是两回事
  • 同一台手机上不要装抖音国内版，也不要留任何中国区 App
  • 一台手机只登一个 TikTok 账号，永远不切换
  • iPhone 比安卓更稳（设备指纹更「干净」，而且 Shadowrocket 好用）

关键设置清单

照着改

信号一致比 IP 类型更重要

✓ 逐项设置
  • 系统语言 → 韩语（至少改成英语，绝对不要留中文）
  • 时区 → 首尔 GMT+9，关掉「自动设置」
  • SIM 卡 → 建议直接不插卡，纯 WiFi 用。这是最容易被忽略的一条：插着中国 SIM 卡连韩国 IP，等于告诉 TikTok「我人在中国装韩国人」。不插卡就没有这个冲突信号
  • App Store / Google Play 地区 → 改成韩国。iPhone 改 Apple ID 国家地区（付款方式选「无」），安卓改不了就从 APKPure 装韩国版
  • 不给 TikTok 定位权限（设置里直接关掉）
  • 节点全局代理，不要只给 TikTok 单独走代理，其他 App 走国内线路会造成信号打架

如果只记一件事：信号一致 > IP 类型

很多人只盯着「IP 是不是住宅」，结果手机语言是中文、时区是北京、插着中国 SIM 卡——这时候就算买最贵的住宅 IP 也没用，TikTok 一眼就看出矛盾。

重要性排序：① 手机语言 / 时区 / 不插中国卡 → ② IP 固定不换 → ③ IP 是不是住宅 → ④ 内容质量（其实这条才是决定生死的）。前三条只决定你的视频能不能被正常推出去，第四条决定推出去之后有没有人看。

系统加固
